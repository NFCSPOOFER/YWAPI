# Contributing

YWAPI is built from community scans and reviewed catalog data.

For now, contributions should go through the project maintainer/community process rather than direct pull requests.

Useful contributions include:

- confirmed scans of missing items
- front and back photos of missing or low-quality assets
- reports of incorrectly matched items
- verified names, release information, and source references

Do not submit private UID/password data to the public API repo. The public API only exposes item identities such as display code, Ark key, numeric ID, names, series, status, and images.
